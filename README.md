✨ To-Do List Web Application

A simple, elegant, and user-friendly To-Do List application designed to make everyday task management easier and more organized.

Stay focused, manage your priorities, and keep track of your daily activities with a clean and responsive interface.

🚀 Features

- ➕ Add Tasks: Quickly create new tasks.
- ✅ Complete Tasks: Mark tasks as completed when finished.
- 🗑️ Delete Tasks: Remove tasks you no longer need.
- 📱 Responsive Design: Works smoothly across desktop, tablet, and mobile devices.
- 🎨 Clean UI: Minimal and attractive user interface.
- ⚡ Fast Performance: Lightweight application with smooth interactions.

🛠️ Technologies Used

Technology| Purpose
HTML5| Structure of the application
CSS3| Styling and responsive design
JavaScript| Functionality and interactivity

💻 Getting Started

Follow these simple steps to run the project locally.

1. Clone this repository:
   
   git clone YOUR_REPOSITORY_URL

2. Open the project folder:
   
   cd To-Do-List-Web-App

3. Open "index.html" in your web browser.

4. Start adding and managing your daily tasks!

🎯 Project Objective

The main objective of this project is to develop a practical task management application while strengthening fundamental web development skills, including HTML structure, CSS styling, DOM manipulation, and JavaScript event handling.
